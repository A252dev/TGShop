# 🤖 TGShop

**TGShop** is a Telegram shop bot built with **C#**, **SQL Server**, and **Entity Framework Core**.  
It simulates a simple e-commerce system where users can browse products, place orders, and manage transactions directly in Telegram.

---

## 🚀 Features

- 🛒 **Product management** – browse and manage products  
- 💳 **Order placement** – place orders through Telegram  
- 🗃️ **Database integration** – SQL Server with EF Core for persistent storage  
- 🤖 **Telegram bot interface** – interact with the shop via Telegram  

---

## 🛠️ Technologies

- **C#** – backend language  
- **.NET / .NET Core** – application framework  
- **Entity Framework Core** – ORM for database operations  
- **SQL Server** – relational database  
- **Telegram Bot API** – interface for user interactions
